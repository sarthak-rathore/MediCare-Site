# 🏥 MediCare Clinic Website

A premium, fully-responsive doctor clinic website for **Dr. Arjun Sharma**, Internal Medicine Specialist, Bandra West, Mumbai.

## 🌟 Features

- **3D Animated Hero** — Canvas-based floating particle orbs
- **Parallax Hero Image** — Subtle depth effect on scroll
- **Scroll Reveal Animations** — Elements animate in on scroll
- **Live Counter Stats** — Animated number counters
- **Testimonial Slider** — Auto-play with touch/swipe support
- **Appointment Form** — Client-side validation + success state
- **Bento Gallery** — Hover-reveal image labels
- **3D Card Tilt** — Service cards respond to mouse movement
- **Active Nav Highlighting** — Highlights current section
- **Floating WhatsApp Button** — Pulsing CTA
- **Back-to-Top Button** — Smooth scroll
- **Mobile-first Responsive** — Works on all screen sizes
- **SEO Optimised** — Proper meta tags, semantic HTML

## 🚀 Deploy to Vercel (GitHub → Vercel)

1. **Push to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial clinic website"
   git remote add origin https://github.com/YOUR_USERNAME/clinic-site.git
   git push -u origin main
   ```

2. **Import to Vercel**:
   - Go to [vercel.com](https://vercel.com)
   - Click **Add New → Project**
   - Import your GitHub repository
   - Vercel auto-detects static site — click **Deploy**
   - Done! Your site is live at `your-project.vercel.app`
